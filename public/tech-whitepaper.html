2. Authentication, Token Rotation & Zero-Trust RBAC

Yoonie enforces strict token segregation: short-lived in-memory Access Tokens (15 minutes) paired with cryptographically secure rotating Refresh Tokens (7 days). Single-flight mutex queues prevent race conditions during silent refresh cycles.

Authentication & Single-Flight Silent Refresh Sequence

When an API call returns 401 Unauthorized, the client NetworkManager intercepts the failure and initiates a single-flight refresh mutex. Parallel network requests are queued until the new token pair resolves, preventing token reuse errors.

3. Concurrency Control, 15-Minute Atomic Holds & Idempotency

In high-velocity flash bookings, traditional read-modify-write patterns cause double-booking disasters. Yoonie guarantees zero over-booking via three strict mechanisms:

  • Atomic Compare-And-Swap (CAS): MongoDB findOneAndUpdate decrements capacity only if { available: { $gte: requestedQty } } evaluates to true in a single atomic database operation.
  • 15-Minute TTL Leases: Temporary reservations acquire a hold token with a hard TTL expiration. Abandoned carts automatically release capacity back to the inventory pool.
  • Idempotency-Key Deduplication: Payment webhooks and reservation submissions require a unique UUID key; duplicate network packets yield cached idempotency records.

4. Enterprise Automation Engine & Node Scheduler

Hospitality operations fail when coordination is manual. Yoonie implements a decoupled, stateful background scheduler (built on Node.js / NestJS @nestjs/schedule and Distributed Workers) handling mission-critical jobs:

🌅 05:30 Dispatch Runner

Cron: 30 5 * * *

Scans today’s guest arrivals, calculates tour pickup sequences, matches airport flights with driver rosters, and populates operational_dispatches.

⏱️ 60-Sec Hold Sweeper

Cron: * * * * *

Finds all inventory_holds where expiresAt <= NOW() and status is PENDING. Atomically increments available inventory back into circulation.

📊 Tour Yield Consolidator

Cron: 0 */2 * * *

Inspects boat excursions 24h prior. If bookings are below economic viability threshold (<4 pax), flags a yield consolidation warning to the operator.
